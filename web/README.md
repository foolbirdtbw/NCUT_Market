# NCUT Market — 前端

北方工业大学校园二手交易平台的前端。无构建步骤：没有 npm、没有打包器、没有 TypeScript。
浏览器直接加载这里的文件，由 `NCUT_Market.Api` 同源托管。

## 文件

| 路径 | 说明 |
|---|---|
| `index.html` | 唯一页面。顶栏 + 公告条 + 一个 `<main id="view">`，视图整块替换 |
| `css/site.css` | 全部样式。皮肤是「网页粗野主义」：纯白底、纯黑字、蓝下划线链接、直角、零过渡零阴影零渐变。深色模式是同一套东西的黑白反相，两套令牌分别在 `:root` 和 `[data-theme="dark"]` |
| `js/ui.js` | 渲染小工具，挂 `window.NM`。`esc()` / `formatDateTime()` 和几个枚举翻译都在这里，所有页面共用 |
| `js/api.js` | 请求入口。定义 `window.api`，在这里把 problem+json 解析成 Error |
| `js/auth.js` | token 的存取、当前用户、登录注册页、忘密码页、顶栏用户区 |
| `js/products.js` | 商品的列表、详情、发布、编辑、我的商品，以及用标题生成封面 |
| `js/messages.js` | 私信：会话列表、会话详情、发消息、交易面板、顶栏未读徽标 |
| `js/notifications.js` | 通知：列表、点开标已读、顶栏未读徽标 |
| `js/announcements.js` | 公告：顶部条、公告页、管理员的发布与删除 |
| `js/dictionaries.js` | 分类和宿舍区两本字典的管理页（增删改），带一道「只有管理员能进」的门 |
| `js/users.js` | 用户管理页（管理员）：按用户名/昵称搜人，给忘了密码的人发一次性重置码 |
| `js/app.js` | 哈希路由、事件委托、主题、启动时的几处拉取（未读徽标、公告条、页脚的在线人数） |
| `vendor/jquery-3.7.1.min.js` | jQuery，原样入库 |

加载顺序有意义：`app.js` 最后，它启动时就要用到 `auth` / `messages` / `notifications` /
`announcements` / `dictionaries` / `users`——建路由表的时候就要引用它们。路由和处理函数都在
各模块自己的文件里，`app.js` 只负责把它们接起来。

## 运行

```bash
dotnet run --project src/NCUT_Market.Api --launch-profile http
```

打开 http://localhost:5087/ 。静态目录由 `Configuration/StaticWebRoot.cs` 解析，启动日志里有：

```
Serving frontend static files from <仓库根>\web
```

## 开发数据

空库看不出任何东西——分页、`srcset`、未读徽标都要有数据才立得起来。

```powershell
powershell -File db/seed-demo.ps1            # 约 20 用户 / 60 商品 / 25 会话
powershell -File db/seed-demo.ps1 -Reset     # 先清掉上一次的，再重来
```

脚本走真实 HTTP 接口，不是直接写表：密码要真哈希，图片要真过一遍 ImageSharp（否则缩略图
文件不存在，列表页全是一片灰底占位），上架还有状态机。占位图用 `System.Drawing` 现场画，
不需要任何新依赖。

跑完会打印账号，也会写一份 `db/demo-accounts.txt`（已 gitignore）。密码统一是 `Demo12345!`，
管理员那个账号的 `role` 是脚本用 SQL 提上去的——仓库里没有提权接口，这是唯一的手段。

**不加 `-Reset` 重跑是累加的**，用户名带随机后缀所以不会冲突，但数据会翻倍。

```bash
sha256sum web/vendor/jquery-3.7.1.min.js
```

**这个文件不要编辑**，改一个字节哈希就对不上。`.gitattributes` 里的 `web/vendor/** -text`
是必须的：本机 `core.autocrlf=true`，否则 git 会在下次 checkout 时把 LF 换成 CRLF，
文件长度和哈希都变。

## 两条不能省的写法

这两条不是"防患于未然"，是"这样写才对"：

**1. 服务端字符串插进 HTML 前必须过 `esc()`。** 视图整体用 `.html()` 重建，
所以每个拼进 HTML 的位置都要转义——标题、描述、昵称、消息正文、公告正文、通知正文、错误详情。
这些视图分散在 `products.js` / `messages.js` / `notifications.js` / `announcements.js` /
`dictionaries.js` / `users.js` 里，改哪一片都要留意。

配套的一条：正文里的换行交给 CSS 的 `white-space: pre-wrap`，**不要把 `\n` 替成 `<br>`**
再拼进去——替了就等于把用户输入又拼了一次 HTML。`ui.js` 里那句可以直接照抄。

**2. 时间字符串不要 `new Date()`。** 接口发的是北京时间的墙上时钟读数，没有时区后缀
（`"2026-09-29T13:43:09.037"`）。按 ES 规范，日期**时间**形式没偏移量时按**浏览器本地时间**
解析，所以 `new Date(v).toLocaleString()` 在任何非 UTC+8 的机器上都显示错——**唯独在开发机
（东八区）上是对的**，所以测不出来。直接按文本重排：

```js
value.replace("T", " ").slice(0, 16)
```

## 已知取舍

| 项 | 说明 |
|---|---|
| 「管理员专属」只是界面上的 | 导航三条链接和首页那几张入口卡按角色隐藏，直接敲 `#/categories` 或 `#/users` 会看到「没有权限」。但 `/api/categories` 和 `/api/dormitory-areas` 的 GET **仍然是匿名的**——商品搜索栏的两个下拉和发布表单全靠它，锁掉整个商品页就废了。而且商品卡片本来就带着分类名和宿舍区名。**这不是访问控制，别当它是**；真正的判定在服务端。`/api/users` 是例外：它整个控制器都要求登录，且服务端逐次查库确认是不是管理员 |
| 重置码只显示这一次 | 管理员页生成完之后，码只在那一次响应里出现；刷新、翻页、重新搜索都会让它消失，库里存的是 SHA-256 摘要，服务端自己也拿不回明文。弄丢了就重新生成一个——重发即撤销，旧码当场失效，所以没有单独的「撤销」按钮 |
| 账号状态是单独一张枚举表 | `ui.js` 里有 `USER_STATUSES` + `userStatusText()`，**不能**复用商品那套 `statusText()`：`UserStatus` 的 2 是「已停用」，`ProductStatus` 的 2 是「在售」，直接混用会把停用显示成在售。两边都是 tinyint、都从 1 开始，编译器和类型都拦不住，所以分开放，并在 `out/check-frontend.js` 里钉了一条断言 |
| 用户搜索只有关键字 | 一个框同时匹配用户名和昵称（包含匹配），没有角色/状态筛选，也没有排序选项。校园站几百个用户，够用 |
| 普通用户照样能用分类/宿舍区筛选 | 上面那条的推论。「不可见」指的是那两本字典的管理页，不是商品搜索 |
| 导航可能闪一下 | 被降权的管理员，本地缓存里的 `role` 是旧的，会在 `/me` 回来之前看到一眼管理入口。页面本身不会错——路由守卫等的是 `/me`。和公告页现在这个折中一模一样 |
| 分类树不处理孤儿 | 父分类被停用时，子分类的 `parentId` 不在结果集里，那一支**不会渲染**。现在的数据不会出现这种情况，真出现了再处理 |
| 分类一次拉 100 条 | 接口分页、树不分页，所以按 `MaxPageSize` 一次拉足，超过 100 个分类就只能显示前 100 个 |
| 会话只显示最新一页消息 | 接口给的是最新 20 条，页面会写明「共 N 条」。往上翻旧消息这一轮不做 |
| 交易面板不做前端预判 | 「下架」「标记已售出」在有待接受提议时照常显示，点了由服务端回一句中文 409。要做得更好就得往公开的商品投影里塞「有人在谈」这类信息，这一轮不值。可操作性仍然由服务端给的事实推出来（`ConversationTradeResponse`），只是不替服务端否决 |
| 交易中的商品留在公开列表里 | 这是有意的：「别人正聊着，商品突然消失」正是要避免的。代价是列表里会出现暂时买不了的东西，靠「交易中」徽标区分 |
| 通知不轮询、没有「全部已读」 | 和私信徽标同一套：只在页面加载、登录状态变化、交易动作之后刷新，一条条点开 |
| 未读数不轮询 | 顶栏那两个数字只在页面加载、登录状态变化、读完一个会话之后刷新。两个人同时开着页面，对方发来的消息不会自动跳出来 |
| 页脚的在线人数同样不轮询 | 只在页面加载时拉一次 `/api/online/count`（匿名可读）。所以它是一个快照：坐在页面上不动二十分钟，数字不会自己变小 |
| 公告条按 id 记「已关闭」 | 关掉之后存在 localStorage 里，刷新不再弹；但发一条新的照样会出现 |
| 前端测试只覆盖纯函数 | `out/check-frontend.js` 测 `esc` / `formatDateTime` / `treeHtml` / `userStatusText` / `coverLines` 这些不碰 DOM 的函数，外加一道「use strict 下有没有漏声明变量」。视图、请求和 canvas 画图得靠手点 |
| 在线人数只算登录用户 | 系统发的是 JWT，服务端没有会话，分不出两个匿名请求是不是同一个人——同一个游客刷新十遍，看到的是十个互不相干的请求。所以这个数的意思是「最近 5 分钟有过请求的活跃账号」，不是「此刻开着页面的人数」。页脚那句「近 5 分钟有活动的登录用户」就是为了不让人误读。`users.last_seen_at` 由 `Program.cs` 里一段中间件盖，只在带 token 的请求上写，匿名请求一次写都不产生 |
| 在线人数每请求一条 UPDATE | `OnlineService.TouchAsync` 每次都盲目写一次，没有节流。节流要先读一次再决定写不写，反而更贵；校园站这个量级不值得优化。写走的是 `ExecuteUpdateAsync`，绕开 `AppDbContext` 的审计规则，所以心跳不会把 `users.updated_at` 也改掉 |
| `last_seen_at` 不建索引、停用账号不算在线 | 前者：`users` 只有几百行，这一列每个请求都要重写，建索引是倒贴写放大。后者：停用账号的 token 照样验得过、照样会被盖时间戳，但一个什么都做不了的账号挂在「在线」上只会把数字说大 |
| 正文 14px 宋体，不是 12px | 当年确实是 12px，但 SimSun 在高分屏上低于 13px 就糊了——那是坏了不是复古。想还原的话改 `:root` 的 `body { font-size }` |
| 按钮面是 `#dfdfdf`，不是纯白 | 「背景只能是纯白」和「按钮必须有 Windows 95 斜面」是打架的——白面配白色上/左边框，斜面根本看不见。所以按钮用系统银灰面，其余一切纯白。输入框同理，凹进去 |
| 弱化色没做成纯黑 | 规范要求正文弱化色也用纯黑、靠结构分层次。但 12px 的成色/时间/页码全黑会糊成一片，用了 `#444444` |
| 只有正文链接有 hover 变色 | 按钮没有 hover 态——当年的按钮就没有，状态只发生在按下那一瞬间。卡片和列表行的 hover 只改边框色或字色，不改底色 |
| 复古感靠结构不靠动效 | 没有 `<marquee>`，没有闪烁，也没有扫描线。零过渡、零动画 |
| 深色模式是黑白反相，不是 CRT | 早先那版黑底绿字终端已经去掉。现在两套主题是同一批令牌换值，组件规则一行不重写；链接在纯黑上只有 1.9:1，所以反相时提亮成 `#66ccff` |
| `/favicon.ico` 404 | 仓库里零图片文件。商品封面是用户传上来的数据，不是仓库里的文件 |
| 生成的封面把字烤进了图里 | 发布之后改标题，封面还是旧标题，只能在详情页删掉重画。这是「生成一张真图片」的必然代价。另外它是位图，不跟深色主题走——同一张图在两种主题下长得一样 |
| 生成封面在浏览器里画，不在服务端 | 服务端画中文要引 `SixLabors.Fonts`，还得往仓库塞一份可再分发的中文字体（十几 MB，授权另算）。浏览器里字体是现成的，`db/seed-demo.ps1` 能画是因为它跑在 Windows 上调系统字体，那是脚本不是服务。代价是发图之前浏览器必须支持 canvas `toBlob`——都是它 |
| 生成封面排在最后，只覆盖发布页 | 手选的照片先传，所以有真照片时它仍然排第一张当封面；一张照片都没选时生成的那张才轮到 `SortOrder = 0`。详情页那个「上传图片」旁没放同一个按钮，这一轮不做 |
| 生成封面不改「上架必须有图」 | `ProductService.PublishAsync` 那道检查保留：至少一张图这条规则本身是对的，这一轮是给它配了条出路，不是把它拆掉。客户端也仍然不预检有没有图，撞到 400 才提示 |
| `/README.md` 可公开访问 | 内容无敏感信息 |
| 前后端同源部署 | 前端绑在 API 进程上，所以没有 CORS 配置 |

`out/` 整体是构建产物，只有 `check-frontend.js` 被 `.gitignore` 反向包含进来。**用 PowerShell 跑**：

```powershell
node out/check-frontend.js
```

Git Bash 会把 `TZ` 吞掉，那样连跑几次其实都是同一个时区，测了等于没测。
